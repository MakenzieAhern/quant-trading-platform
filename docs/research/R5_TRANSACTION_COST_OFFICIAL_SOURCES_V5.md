# R5 transaction-cost official-source closure v5

## Result

The public-source question about customer commission composition is closed.
The official Guangdong CSRC notice dated 2012-08-24 requires securities firms
to distinguish net commission (excluding regulatory fees) from all-in
commission (including regulatory fees) according to the customer's written
agreement. Where no written convention exists, the account's actual charging
practice controls.

This is not a universal fee formula. It proves that generic public rules cannot
select the Quant Trading Platform research-account convention. The executable
commission assumption is unchanged; full-history acceptance requires an
account contract or an explicit human research convention.
