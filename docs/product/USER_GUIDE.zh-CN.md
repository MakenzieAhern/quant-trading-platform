# A 股量化工作台操作指南（v1.2 开发版）

本指南对应本机开发中的产品界面，不代表 v1.2.0 已发布。平台只做本地研究和模拟，不连接真实券商，也不会发送真实资金订单。历史表现不保证未来收益。

## 打开与确认数据

在服务已运行时，用本机浏览器打开 [工作台](http://localhost:5173/)。先看顶部“服务在线”以及旁边独立显示的数据模式和日期；服务在线**不等于**行情是今天的，也不等于来源已审计通过。到[数据中心](http://localhost:5173/data)核对可用数据、日期和来源。需要中文或英文、浅色或深色界面，可在[设置](http://localhost:5173/settings)切换；语言不会改变交易日期或计算结果。

本机已设置 Docker Desktop 登录后启动，项目容器也已设置为非手动停止时自动恢复。但 2026-09-24 实际重启并登录 Windows 后，Docker Desktop 在检查时并未运行；维护者手动启动现有程序后，服务与原有卷才恢复。因此目前**不能**承诺登录后直接打开链接就可用，也未通过免终端的一键启动验收。若网页打不开，不要重装 Docker、清空卷或重抓数据；先确认 Docker Desktop 已运行，再请维护者检查项目服务。服务恢复后重新打开同一任务链接，核对已保存的任务和结果。

## 四种模式不要混用

| 模式 | 可以用来做什么 | 不能说明什么 |
|---|---|---|
| 历史研究 | 用已保存的 A 股数据做个人探索实验 | 已查看的区间不是新的未见样本，也不是未来收益预测 |
| 历史回放 | 让模拟账户逐日走过已存储的交易日 | 不是新到达的实时或日终行情 |
| 合成演示 | 无私有历史数据时学习配置、任务和结果页面 | 虚构价格不是市场证据 |
| 真实新行情前向模拟 | 目标模式：用户启动后接收新完成交易日数据再模拟处理 | **尚未开放**；数据使用权限、当期规则及真实到达验收未通过 |

## 从策略到结果

1. 在[工作台](http://localhost:5173/)选择“开始引导式回测”。先查看已注册策略的买卖规则、风险和所需数据；不要把策略说明理解成收益推荐。
2. 按四步填写策略、本金与日期/股票范围、成本与风险、最终确认。高级参数按需展开；保存草稿后可回到首页继续。券商佣金及最低佣金是模拟假设，不是已核实报价；在结果页核对实际成本明细。提交前确认数据模式和区间标签。
3. 运行后到[研究列表](http://localhost:5173/experiments)或[任务中心](http://localhost:5173/tasks)找回同一任务。离开页面或刷新不会把已保存的任务变成新任务。只有标为“已完成”的任务才有完整结果；中断、取消和失败记录不展示为成功。
4. 在结果页先看收益、最大回撤、成本、基准和限制，再展开交易、持仓、风控和“为什么订单成交或未成交”。“显示完整精度”只改变展示；日期筛选也不重算完整区间指标。技术原因码可展开核查。
5. 从列表选择 2–3 个已完成实验进行比较，并先检查数据版本、区间、本金、成本、风险和策略版本是否一致。模拟调仓预览若存在，必须连同其日期、数据快照和风险拒绝一起阅读；旧结果可能没有预览。结果页可下载带元数据的 JSON 报告和 CSV 明细；本机真实 Chrome 已验证两种下载完成。若报告已准备好但浏览器未自动开始下载，请点击页面的“保存已准备的报告”链接并核对下载记录；若报告准备失败，检查服务状态后再点下载按钮。不要仅凭按钮点击就认定保存成功。

## 模拟账户与中断恢复

到[模拟账户](http://localhost:5173/paper)选择明确标记的合成演示或历史回放。由用户主动启动；可在页面暂停、恢复或停止，并查看现金、持仓、订单、成交和日志。它们不是真实交易。真实新行情前向模式尚不可用，不要把历史补录当作新的市场到达。

若研究任务显示“已取消”或“已中断”，打开该任务查看原因；“创建或打开关联重试”沿用原配置，原记录不会被覆盖。重复请求会打开同一关联尝试。模拟账户在服务意外中断后可能标为“已中断”而不自动续跑，应阅读页面说明，再决定是否新建会话；不要假定失联期间发生了成交。服务离线、超时或无数据时，先用页面的重试/返回入口；如果仍失败，记下任务链接和屏幕上的技术原因交给维护者，不要清除 PostgreSQL、Redis 或 Docker 卷。

当前开发数据库曾发生恢复事件：两个晚于有效备份的模拟会话（短 ID `4b64380f`、`07d72259`）未能找回，不能把它们当作仍可查询的持久记录。同一物理盘上的备份也不等于独立灾难恢复。在该缺口解决前，不要把此开发版当作可靠的长期账户账本。
